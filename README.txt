# 태초 시즌3 출정 준비 — 웹사이트

이 폴더는 47장 PPT를 인터넷 공유용 정적 웹사이트로 만든 버전입니다.

## 가장 쉬운 사용법
1. 폴더 안의 `index.html`을 더블클릭합니다.
2. Chrome/Edge/Whale에서 사이트가 열립니다.
3. 인터넷에 올리려면 폴더 전체를 그대로 업로드합니다.

## 포함 기능
- 47장 슬라이드 전체 보기
- 10개 주제 목차
- PC 좌우 버튼 / 키보드 페이지 이동
- 휴대폰 좌우 스와이프
- 모바일 전용 하단 메뉴
- 모바일 목차 슬라이드 메뉴
- 슬라이드 탭/클릭 확대 보기
- 확대 화면 핀치 줌 / 마우스 휠 줌 / 드래그 이동
- 전체화면
- 진행률 및 현재 페이지 표시
- 외부 서버나 데이터베이스가 필요 없는 정적 사이트

## 인터넷 공유
이 사이트는 정적 HTML/CSS/JS와 이미지 파일만 사용하므로 GitHub Pages, Netlify, Cloudflare Pages 등 정적 호스팅에 올릴 수 있습니다.

### GitHub Pages를 사용할 경우
- GitHub 저장소를 하나 만든 뒤 이 폴더의 파일을 업로드
- Settings → Pages에서 배포할 브랜치/폴더 선택
- 잠시 기다리면 `https://계정명.github.io/저장소명/` 형태의 주소가 생성됩니다.

주의: `index.html`, `style.css`, `script.js`, `slides` 폴더는 같은 구조를 유지해야 합니다.
